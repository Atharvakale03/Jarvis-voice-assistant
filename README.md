# 🎙️ Jarvis Voice Assistant

A simple Python-based voice assistant that listens to voice commands and performs different tasks using speech recognition, text-to-speech, web browsing, music links, and NewsAPI.

## 🚀 Features

- 🎤 Voice command recognition
- 🔊 Text-to-speech responses
- 🌐 Open Google, Facebook, YouTube, and LinkedIn
- 🎵 Play songs from a custom music library
- 📰 Fetch and read top Indian news headlines
- 🤖 Wake-word activation using "Jarvis"
- 🌐 Google Speech Recognition API
- 🔊 Google Text-to-Speech (gTTS)

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- PyAudio
- gTTS
- pygame
- pyttsx3
- Requests
- Webbrowser
- NewsAPI
